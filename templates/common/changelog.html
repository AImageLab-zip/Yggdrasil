This page stays public -- the version link in the footer renders on /login/, on the landing page and on the anonymous demo -- so no login gate here: for anonymous visitors the rail renders logo-only (its links gate on user.is_authenticated) and the topbar shows no user menu. The release list is parsed out of CHANGELOG.md by common.views._parse_changelog, so this page and the GitHub release notes read the same source. That is deliberate: the compiled stylesheet predates the current templates and scripts/build_css.sh cannot reproduce it byte for byte (see its header), so a class that is not already in the build silently does nothing.
