{% extends 'base.html' %} {% load icons %} {% comment %} Shared shell for the branded HTTP error pages (404 / 403 / 410 / 500). Django's default handlers render `.html` from the template search path when one exists, so 404.html, 403.html and 500.html are picked up by adding the files -- no handler404/handler500 wiring is needed. 410.html has no default handler; it is here so a view that answers 410 can render a page that matches the others. **500.html is rendered WITHOUT context processors** (django.views.defaults .server_error calls template.render() with no request), so nothing here may depend on context. `app_version`, `site_maintenance` and `user` are therefore untouched by this shell: it uses only `{% url %}` and `{% static %}`, which are tags and need no context. 500.html additionally blanks the nav and the footer, because base.html's footer does render `{{ app_version }}`. {% endcomment %} {% comment %} The nav reverses namespaced URLs (`patient_list` and friends), which do not resolve when the error came from the admin or any other non-domain prefix -- a NoReverseMatch here fires *while Django is already handling an error*.
