3D Viewer Instructions
IOS Scanner Viewer
Mouse Controls
  • Left-click + drag: Rotate the view
  • Scroll wheel: Zoom in/out
  • Right-click + drag: Pan the view
Jaw Visibility
  • U button: Toggle upper jaw visibility
  • L button: Toggle lower jaw visibility
  • Reset button: Return to default view
Display Options
  • Wireframe: Toggle wireframe mode for better detail
  • Solid: Default shaded view
Landmark Annotation
  • Annotation button: Show saved landmarks and enter annotation mode
  • Tooth and type: Select the FDI tooth and landmark type
  • Shift + left-click: Place the selected landmark on the matching jaw surface
  • Select: Select a marker, then delete it or undo recent changes
  • Save: Persist changes when you are finished
CBCT Volume Viewer
Mouse Controls
  • Left-click + drag: Pan/move the view
  • Scroll wheel: Scroll through slices
  • Shift + scroll: Faster scrolling
  • Ctrl + scroll: Zoom in/out
  • Ruler tool: Click the ruler above the 4-window grid, then click two points (can be on different slices/views). Hover a point or line to see the 3D Euclidean distance in mm.
  • Level / Window: Adjust contrast live across every loaded CBCT view.
Rendering Options
  • 3D only: Lazily load the renderer and expand it without discarding slice state. Select it again, use Exit 3D, or press Escape to return.
  • Attenuated MIP: Default projection with front-to-back attenuation for depth cues.
  • MIP: Show the maximum intensity encountered along each ray.
  • Shaded Volume: Gradient-lit volume rendering. A native NiiVue fallback is used when the custom shader is unavailable.
  • Reset 3D camera: Restore the initial front-facing camera.
